A Streamlit travel recommendation app that learns a user's trip preferences from photo-pair choices, context answers, and adaptive survey inputs. It ranks 125 destinations with a hybrid recommender built around a 13-dimensional city profile: 8 physical dimensions and 5 sociological dimensions.

The project is designed as an end-to-end data science portfolio piece: data preparation, active preference collection, ranking logic, synthetic evaluation, app UI, session logging, tests, and deployment notes are all included.

## Highlights

- Adaptive onboarding with photo-pair comparisons and survey questions.
- Dual 8+5 destination representation for physical and sociological preference matching.
- Hybrid ranking pipeline with scope filters, quality penalties, and safety-aware reranking.
- Anonymous session logging for future model improvement.
- Production-oriented deployment blueprint with systemd, nginx sticky routing, and Cloudflare Tunnel.
- Test coverage for configuration, active learning, recommendation behavior, leakage checks, UI helpers, and evaluation guardrails.

## Evaluation Snapshot

Synthetic ablation results are generated by `notebooks/01_synthetic_eval.py` and stored in `notebooks/ablation_sonuc.md`.

| Variant | NDCG@3 | Hit@3 |
|---|---:|---:|
| Random ranking | 0.048 | 0.147 |
| Static data order | 0.128 | 0.167 |
| Baseline flat cosine | 0.864 | 0.977 |
| Weighted flat cosine | 0.865 | 0.977 |
| Dual weighted cosine | 0.929 | 0.997 |
| Hybrid score | 0.929 | 0.997 |
| Full recommendation pipeline | 0.918 | 0.990 |

The strongest result comes from separating the destination vector into physical and sociological groups, then weighting those groups independently. In this synthetic setup, the dual 8+5 representation improves NDCG@3 by 0.064 over flat 13-dimensional cosine scoring.

## System Architecture

```text
User scope and context
        |
        v
Stage 0: destination scope filter
        |
        v
Stage 1: photo-pair preference collection
        |
        v
Stage 1.5: region multi-pick and adaptive survey
        |
        v
Stage 2: hybrid ranking in model/recommend.py
        |
        v
Stage 3: anonymous feedback and session logging
```

The ranking layer combines similarity scoring, candidate-pool filtering, and post-score quality signals such as safety, pollution, livability, and health risk. Those quality and risk fields are applied after vector similarity rather than being baked into the core 13-dimensional representation.

## Quick Start

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
streamlit run app/main.py
```

The app binds to `127.0.0.1:8501` by default through `.streamlit/config.toml`.

## Deployment

The `deploy/` directory documents a local production-style setup:

- Streamlit bound to loopback only.
- Four systemd-managed replicas.
- nginx reverse proxy with IP-based sticky routing for Streamlit session state.
- Cloudflare Tunnel for outbound-only public access.
- Session-log backup script with no hardcoded personal path.

See `deploy/README.md` for the full setup.

## Notes

This repository does not commit user session logs, local secrets, virtual environments, or generated cache directories. Runtime feedback is written to `data/sessions.jsonl`, which is intentionally ignored by Git.
